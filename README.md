# Досье Плюс — Этап 1

Ядро: приём книги покупок/продаж (Раздел 8/9 декларации по НДС), парсинг,
правила красных флагов, отчёт в Telegram. Без внешних API, без базы данных —
это появится на Этапах 2-3.

## Файлы

- `parser.py` — парсер обеих книг (проверен на реальных файлах: 1866+3000 операций, 254 контрагента)
- `rules.py` — правила красных флагов (круглые суммы, суммы у порога, резкий скачок, сторно, транзитные операции)
- `book_detect.py` — определяет тип файла (покупки/продажи) по содержимому
- `report.py` — форматирует итоговое сообщение
- `config.py`, `keyboards.py`, `bot.py`, `handlers/` — сам бот на aiogram 3

## Шаг 1 — получить токен бота

1. В Telegram напишите **@BotFather**
2. Команда `/newbot`, укажите имя — **Досье Плюс**
3. Укажите юзернейм, оканчивающийся на `bot` (например `DosjePlusBot`, если свободен)
4. BotFather пришлёт токен вида `123456:ABC-...` — это и есть `BOT_TOKEN`

## Шаг 2 — узнать свой Telegram ID

Напишите **@userinfobot** в Telegram — он пришлёт ваш числовой ID. Это `OWNER_ID`
(пригодится на Этапе 5 для админки, но переменную можно завести сразу).

## Шаг 3 — выложить код на GitHub

```bash
cd dosje_plus
git init
git add .
git commit -m "Этап 1: парсер книги + правила риска + базовый бот"
```

Создайте пустой репозиторий на github.com (без README/лицензии), затем:

```bash
git remote add origin https://github.com/<ваш-юзернейм>/dosje-plus.git
git branch -M main
git push -u origin main
```

**Важно:** файл `.env` (если заведёте локально) не должен попасть в репозиторий — см. `.gitignore` ниже.

## Шаг 4 — задеплоить на Railway

1. railway.app → **New Project** → **Deploy from GitHub repo** → выбрать `dosje-plus`
2. Railway сам увидит `requirements.txt` и подготовит Python-окружение
3. Вкладка **Variables** → добавить:
   - `BOT_TOKEN` = токен из шага 1
   - `OWNER_ID` = ваш ID из шага 2
4. **Settings → Deploy → Start Command**: `python bot.py`
5. Deploy — через минуту бот должен отвечать на `/start` в Telegram

## Проверка

Отправьте боту `/start`, затем нажмите «📊 Проверить книгу» и пришлите оба файла
(Раздел 8 и Раздел 9 — в любом порядке). Бот пришлёт сводку и список рисков.
